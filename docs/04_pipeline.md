# Пайплайн одного эпизода

Первый эпизод займёт 5–6 часов — это обучение. Цель с 4-го эпизода — **1,5–2 часа**.

```
Сценарий → Шот-лист → Ключевые кадры → Анимация → Звук → Сборка → Публикация
 (Claude)   (Claude)    (ChatGPT)      (Veo/Kling) (Veo/11L) (CapCut)  (TikTok Studio)
  10 мин     10 мин      20–30 мин      30–45 мин   10 мин    30 мин     5 мин
```

## Папки

```
monolith/
  00_character/     мастер-референсы персонажей
  01_scripts/       сценарии и шот-листы
  EP01_schiefe-fliese/
    keyframes/      kf1.png, kf2.png ...
    clips/          c1_v1.mp4, c1_v2.mp4 ... (все попытки)
    audio/
    EP01_final.mp4
```

Называть клипы `c{номер}_v{попытка}` — через неделю будет 200 файлов, без системы утонешь.

---

## 1. Сценарий и шот-лист (Claude)

```
Ты — сценарист коротких мультфильмов для TikTok. Сериал "Monolith":
[вставить описание персонажей из 02_character.md]

Эпизод: [название и идея из 03_episodes.md].

Сделай:
1. 5 вариантов хука на немецком (до 7 слов, текст на экране в первые 1,5 сек).
2. Шот-лист из 3–5 клипов: в каждом ОДНО простое действие, длина 3–6 сек.
3. Для каждого клипа — промпт для генератора видео на английском в формате:
   [CHARACTER] + действие + окружение + камера + [STYLE] + звук.
4. Звук для каждого клипа (SFX, без речи).
5. Подпись к посту (≤100 символов) + 4 хэштега.
Правило: никаких сложных действий руками, никаких логотипов и надписей в кадре.
```

## 2. Ключевые кадры (ChatGPT)

Для каждого клипа — **первый кадр** картинкой. Это главный приём консистентности: видеогенератор анимирует кадр, где персонаж уже правильный.

```
[приложить monolith_master.png]
Using this exact character, create a still frame: [описание сцены].
[CHARACTER]. [STYLE]. Vertical 9:16.
```

Проверка каждого кадра: каска оранжевая? глаза те же? форма блока та же? Нет — перегенерировать.

## 3. Анимация

### Вариант A — Veo 3.1 (основной, со звуком)
Загрузить ключевой кадр как первый кадр (или как референс-«ингредиент»), промпт:

```
[CHARACTER]. ACTION: [одно действие, напр. "freezes, stares at a crooked tile, his left eye twitches"].
CAMERA: [static medium shot / slow push-in / close-up].
[STYLE].
AUDIO: [напр. "heavy cartoon footsteps stop abruptly, a small 'ding' sound, quiet grumbling, no speech, no music"].
```

Музыку в генерации **не просить** — её добавим в TikTok, иначе две музыки наложатся.

### Вариант B — Kling (image-to-video)
Тот же ключевой кадр + промпт только про **движение**:
```
The character [действие]. Camera [движение]. Keep the character design exactly as in the image. Smooth cartoon animation.
```
Режим Standard. Pro — только для самого важного кадра эпизода.

### Отбраковка
- Персонаж изменился → в мусор
- Лишние руки/ноги, морфинг → в мусор
- Действие не то, но персонаж ок → можно обрезать до удачной части

Норма: годен 1 из 2–3. Если брака больше — упростить действие в промпте, а не генерировать то же самое 10 раз.

## 4. Звук

- Звук Veo устраивает → готово.
- Нет (или клип из Kling) → ElevenLabs Sound Effects: `cartoon heavy footsteps`, `cartoon fainting thud`, `grumpy cartoon grumble, no words`. Генерировать пачкой, складывать в библиотеку звуков — они переиспользуются во всех сериях.
- **Фирменный звук Monolith** (его «хмпф») — сгенерировать один раз, использовать в каждой серии. Это как узнаваемая фраза.

## 5. Сборка (CapCut)

1. Проект 1080×1920, 30 fps. Сохранить как шаблон после 1-го эпизода.
2. Клипы встык, монтаж плотный: первые 0,5 сек — уже действие.
3. Текст-хук сверху, крупный жирный шрифт, белый с чёрной обводкой. Держится 2–3 сек.
4. В конце — маленький вотермарк `@monolith…` в углу (ролики будут перезаливать).
5. Зациклить: последний кадр по возможности стыкуется с первым.
6. Экспорт без музыки (музыка — в TikTok).

## 6. Публикация (TikTok Studio, с компьютера)

- Загрузить, добавить трек/популярный звук на низкой громкости.
- **Включить метку «AI-generated content»** — обязательно, иначе TikTok может удалить или урезать охват.
- Обложка — кадр с самым смешным выражением лица.
- Отложенная публикация: будни 17:00–20:00, выходные 11:00–13:00.

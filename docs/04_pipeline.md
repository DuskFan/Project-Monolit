# Пайплайн одного ролика

Цель — **2–3 часа на ролик** после того, как первый собран и шаблон в CapCut готов. Первый ролик займёт 5–6 часов — это нормально, это обучение.

```
Сценарий → Исходники → AI-обработка → Голос → Монтаж → Согласование → Публикация
 (Claude)   (телефон)    (Kling/GPT)  (11Labs)  (CapCut)    (батя)      (×3 платформы)
  15 мин    на объекте     30–45 мин   10 мин    60–90 мин   ≤24 ч         15 мин
```

---

## Шаг 0. Разовая подготовка (фаза 0)

1. **Насмотренность — 30 минут, с таймером.** Найти в TikTok по `#fliesenleger`, `#tiler`, `#tiling` 10 роликов с большими просмотрами. Записать в таблицу: хук (первые 2 сек), длина, есть ли голос, как сделан CTA. Закрыть. Больше не листать.
2. **Шаблон CapCut:** проект 1080×1920, 30 fps; стиль субтитров (шрифт, антрацитовая плашка, оранжевое выделение ключевого слова); лого-вотермарк в углу; конечная заставка 3 сек. Сохранить как шаблон.
3. **Голос ElevenLabs:** перебрать 5–10 немецких голосов из библиотеки, выбрать один мужской, спокойный, «бригадирский», не рекламный. Записать Voice ID. Один голос на все ролики — это часть бренда.
4. **Папки:**
   ```
   monolith/
     00_brand/        лого, шрифты, цвета
     01_raw/          исходники с телефона, по дате
     02_ai/           выходы Kling/ChatGPT
     03_vo/           голос
     04_projects/     проекты CapCut
     05_export/       финальные mp4: 01_wir-suchen-dich_v1.mp4
   ```

## Шаг 1. Съёмка на объекте (ежедневно, 5–10 минут)

Ты и так на объекте каждый день — это главное преимущество проекта.

- Телефон **вертикально**, 1080p/4K 30fps, протереть объектив (на стройке он всегда в пыли).
- Каждый кадр **3–6 секунд**, держать неподвижно или плавное движение.
- Снимать **процесс крупно**: руки, шпатель, резка, уровень, затирка. Звук оставлять — скрежет и щелчки отлично работают как ASMR.
- **«До» на каждом новом объекте**, с фиксированного ракурса (запомни точку, где стоял).
- Без лиц тех, кто не дал согласия; без адресов, номеров машин, документов клиента.
- Обзывать файлы не надо — разберёшь вечером по папкам (это твоя тема — структурирование).

Шот-лист на неделю — выписать из сценариев все 🎥-кадры и вычёркивать.

## Шаг 2. Сценарий (Claude)

Промпт-шаблон:

```
Ты — сценарист коротких вертикальных роликов для немецкой фирмы по укладке плитки MS Infrastructure.
Аудитория: [плиточники и помощники в регионе X / частные клиенты].
Вот черновик сценария: [вставить из 03_videos.md].
Факты от руководителя: [вставить бриф].

Сделай:
1. 5 альтернативных хуков на немецком (до 6 слов, первые 1,5 сек).
2. Финальный текст VO на немецком, разговорный, не рекламный, ≤ [N] слов (≈2,5 слова/сек).
3. Текст на экране (≤5 слов на кадр).
4. RU-перевод субтитров.
5. Подпись к посту (≤150 символов) + 5 хэштегов.
Не придумывай факты, которых нет в брифе.
```

Немецкий текст VO — прогнать ещё раз через ChatGPT: «Klingt das natürlich für einen deutschen Handwerker? Korrigiere nur, was unnatürlich klingt.»

## Шаг 3. AI-обработка

### Kling — image-to-video (оживление реальных фото)
- Вход: **реальное фото с объекта**, вертикальное.
- Длина 5 сек, режим Standard (Pro — только для 1–2 ключевых кадров, жрёт кредиты).
- Промпт описывает **только движение камеры**, не содержимое:
  ```
  Slow cinematic dolly forward, subtle parallax, natural daylight, static scene, no people moving, photorealistic.
  ```
  ```
  Slow orbit around the bathroom, smooth camera motion, keep all tiles and grout lines perfectly straight and unchanged.
  ```
- Проверка каждого результата: швы прямые? плитка не «плывёт»? Если плывёт — в мусор, генерировать заново или использовать статичное фото с Ken Burns в CapCut.

### Kling / Sora — атмосферные вставки (🎨)
Только то, где фейк не виден и не важен: рассвет, фургон в тумане, пыль в луче света, макро текстуры плитки.
```
Vertical 9:16. Early morning fog over a residential construction site in Germany, a white work van parked, warm sunrise light, cinematic, realistic, no text, no logos.
```

### ChatGPT — изображения
Обложки, фон для титров, графика для #7. Всегда в фирменных цветах `#2B2D31` / `#E86A1E`.

## Шаг 4. Голос (ElevenLabs)

- Модель: самая новая мультиязычная, выбранный Voice ID.
- Stability ~45–55 %, Similarity ~75 %. Генерировать **по фразам**, а не весь текст сразу — проще менять и монтировать.
- Немецкие слова с акцентом/неверным ударением — переписать фонетически или разбить запятой.
- Экспорт mp3/wav → `03_vo/`.

## Шаг 5. Монтаж (CapCut)

1. Открыть шаблон → закинуть VO на дорожку → под него резать видео (а не наоборот).
2. **Первый кадр = хук**, без лого, без заставки. Лого только вотермарком.
3. Склейки каждые 1,5–3 сек.
4. Автосубтитры → **вычитать вручную** (немецкий автосубтитры коверкают) → применить стиль.
5. Для вакансий — второй слой субтитров RU, мельче, сверху.
6. Музыка: на 15–20 % громкости под голосом. Для TikTok — подставлять трек из Commercial Music Library уже при загрузке.
7. Экспорт: 1080×1920, 30 fps, высокий битрейт → `05_export/NN_name_v1.mp4`.

## Шаг 6. Согласование с батей

- Отправить mp4 в мессенджер + текст подписи.
- Одна итерация правок. Вторая — только если факт неверный.
- Нет ответа 24 ч = согласовано (это в контракте).

## Шаг 7. Публикация

| Платформа | Как | Особенности |
|-----------|-----|-------------|
| TikTok | TikTok Studio (веб), отложенная публикация | Включить **«AI-generated content»**; музыка из CML; обложка — кадр с хуком |
| Instagram Reels | Meta Business Suite, отложенно | Публиковать **без водяного знака TikTok** — заливать исходный mp4 |
| Facebook Reels | Meta Business Suite — галочка «также в Facebook» | — |
| Telegram | Пост в канал: видео + подпись RU/DE | Для вакансий — обязательно |

**Время публикации:** будни 17:00–19:00 (рабочие едут домой), выходные 10:00–12:00. Проверить потом по аналитике TikTok Studio, но не раньше чем через неделю.

## Шаг 8. После публикации

- Отвечать на комментарии **в течение первого часа** — это ускоряет охват. Делать это одной сессией, не дежурить.
- Отклики (личка) → таблица: дата, имя, платформа, профессия, опыт, контакт, статус. Передавать бате ежедневно.
- Через 48 ч записать: просмотры, досмотры, комментарии, отклики → `05_calendar.md`, раздел «Результаты».

# 10 сценариев

Формат всех роликов: **9:16, 1080×1920, 15–40 сек**, субтитры обязательно (80% смотрят без звука), хук в первые 1,5 сек, CTA в конце.

Легенда:
- 🎥 **REAL** — снимаешь на телефон на объекте
- 🤖 **AI-I2V** — реальное фото → Kling image-to-video
- 🎨 **AI-GEN** — полностью сгенерировано (только атмосфера, без рук и без процесса укладки)
- 🎙 **VO** — голос ElevenLabs
- `[ФАКТ: …]` — заполняет батя, без этого ролик не публикуем

Распределение: **7 роликов — рабочая сила, 3 — клиенты**. Порядок публикации выстроен так, чтобы первым шёл самый понятный оффер.

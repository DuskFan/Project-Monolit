# Стек и бюджет

Бюджет: **100 €** + ChatGPT Plus + Claude Pro + $100 Claude API.

|------------|----------|------|----------|--------|
| **Claude Pro** | Сценарии, хуки, переводы, подписи, контроль качества | уже есть | — | ✅ основной «мозг» |

## Про $100 Claude API

Честно: **для этого проекта он почти не нужен.** Claude Pro закрывает все сценарии и тексты через чат. API имеет смысл, только если автоматизируем что-то пачкой:

- скрипт: 10 сценариев → автоматический перевод субтитров DE→RU + генерация вариантов подписей и хэштегов;
- Telegram-бот-анкета для откликов (Claude фильтрует и структурирует анкеты — это прямо твоя тема, структурирование данных).

Рекомендация: не трогать купон в первые две недели. Если на фазе 3 останется время — сделать бота-анкету, это сильный бонус к сдаче проекта.

## Что сознательно НЕ берём

- **HeyGen / Synthesia (AI-аватары-ведущие)** — «говорящая голова», которая не человек, для найма работяг выглядит как развод. Плиточник хочет видеть живого шефа и живую стройку.
- **Runway / Luma / Pika параллельно с Kling** — дублирование. Один генератор видео достаточно.
- **Годовые планы** — проект на 3 недели.
- **Клонирование голоса бати** — технически можно (ElevenLabs Starter позволяет instant clone), но если батя не говорит свободно по-немецки, а в ролике его голос звучит идеально — мастер позвонит, и будет неловко. Только с его согласия и только на тот язык, на котором он реально говорит.

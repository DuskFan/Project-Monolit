# Project Monolith

TikTok-сериал, полностью сгенерированный ИИ, про немецкую стройку глазами «наших».
Зрители — румынские, молдавские и русскоязычные рабочие в Германии.

**Командный центр (главный источник правды):** https://claude.ai/artifact/GJiVqikWzUoKWsFY9TmSfx
Копия страницы — [`command-center/index.html`](command-center/index.html).

## Герои

- **Monolith** — бетонный блок в оранжевой каске, молчаливый перфекционист.
- **Herr Zollstock** — немецкий шеф из складного метра, говорит 1–4 немецких слова.
- **Kachel** — стажёр-плитка.

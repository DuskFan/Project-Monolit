# Project Monolith

Кинематографичная ИИ-вселенная фирмы **MC Infrastructure** (укладка плитки, Германия) в TikTok.
Знак — [`brand/mc2_logo.svg`](brand/mc2_logo.svg), почта — mc.infrastructure.de@gmail.com.
Никаких мультперсонажей: материал, свет, точность. Лиц нет — только силуэты и руки.
**Язык роликов — русский** (зрители — русскоязычные рабочие в Германии). Вторая строка DE или RO в титрах — по желанию.

**Штаб (главный источник правды):** https://claude.ai/artifact/GJiVqikWzUoKWsFY9TmSfx
Копия страницы — [`command-center/index.html`](command-center/index.html).

## Как пользоваться штабом

1. **Маршрут** — первый раздел. Курс с нуля для новичка: Азбука (что такое промпт, ключевой кадр, Veo, кредиты), рабочее место (Mac или Windows, папки одной командой), подписки, бренд, первый ролик V01 по этапам, конвейер V02–V10, методичка, прокачка.
   В каждом шаге: зачем он нужен, что нажать, что должно получиться, что делать, если не вышло.
2. **Наставник** — кнопка справа внизу. Это Claude внутри штаба: объясняет по-русски, видит скриншоты и сам правит сценарии, кадры и стиль бренда по словам («во втором кадре поставь ночь», «сделай цвет теплее для всех роликов»).
3. **Журнал затыков** — внизу «Маршрута». Сюда попадает всё, где инструкция не сработала. Напиши Claude в основном чате «посмотри журнал штаба» — он прочитает и исправит инструкции.
4. **Промпты** — штаб собирает сам из полей кадра. Под каждым английским промптом есть русский перевод и кнопка «Что это?». Описание кадра можно писать по-русски, кнопка «Перевести» сделает английский.

## Формула: видео строится как объект

Заказ (бриф) → Чертёж (раскадровка) → Плитка (ключевые кадры) → Укладка (движение) → Затирка (звук) → Отделка (монтаж) → Сдача (эфир) → Осмотр (цифры).

Весь путь одним файлом — [`docs/01_metodichka.md`](docs/01_metodichka.md). Свежую версию под свою систему скачивает кнопка «Методичка» в штабе.

## Пять законов вселенной

1. Материал — главный герой.
2. Лиц не показываем: силуэты, спины, руки в перчатках.
3. Свет — только синий час, золотой час или натриевая ночь.
4. Лазерная линия — подпись серии в каждом ролике.
5. Правда: ИИ-кадр — образ, а не «наш объект». Метка ИИ и «Создано ИИ · KI-Visualisierung» всегда.

## Голос

- Ярусы I–II — без голоса, строка на экране по-русски.
- Ярус III — живой голос бати или Миши по-русски, чистка в ElevenLabs Voice Isolator.
- Ярус IV — ИИ-диктор по-русски в ElevenLabs.

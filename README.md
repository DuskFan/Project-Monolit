## 1. Цель

Запустить присутствие MS Infrastructure в соцсетях и выпустить **10 коротких роликов, сделанных с помощью нейросетей**, которые:

1. **В первую очередь** привлекают рабочую силу (плиточники, помощники).
2. **Во вторую** — клиентов (частники, генподрядчики).

## 3. Ключевое решение по подходу

**Реальная работа — реальными кадрами. Нейросети — упаковка.**

Полностью сгенерированное видео укладки плитки сейчас палится сразу: кривые швы, «плавающие» руки, плитка, которая ведёт себя как желе. Для строительной фирмы это убивает главное — доверие. Плиточник за 2 секунды увидит фейк и пролистает.

Поэтому гибрид:

| Что | Чем делаем |
|-----|-----------|
| Сценарии, хуки, тексты, подписи | Claude / ChatGPT |
| Голос за кадром | ElevenLabs |
| Оживление реальных фото объектов (image-to-video) | Kling |
| Заставки, фоны, обложки, лого | ChatGPT (генерация изображений) |
| Атмосферные вставки без людей (рассвет над стройкой, крупный план плитки) | Kling / Sora |
| Монтаж, субтитры, музыка | CapCut |
| Исходники | Телефон Миши на объектах (ты и так полевой коллектор данных) |

Условие «с помощью нейросети» из контракта выполнено полностью — каждый ролик собран через AI-пайплайн.
